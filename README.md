# Aichan Anime Cover Manager

## Overview

A personal Java application for managing anime collection covers.

## Features

* Search anime metadata using the TMDB API.
* Retrieve landscape backdrop images for anime collection covers.
* Use video frame extraction as a fallback when no suitable backdrop is available.
* Cache cover images locally for reuse.

## Technology

* Java
* Spring Boot
* TMDB API
* FFmpeg

## Intended Use

Personal media organization and anime collection cover management.
